# Project Praktikum Python

Dokumentasi dan repositori resmi untuk latihan dasar praktikum pemrograman Python dan penggunaan Git/GitHub.

## Deskripsi Proyek
Proyek ini berisi skrip Python sederhana (`halo.py` dan `tampil.py`) yang melatih penggunaan input/output, penanganan error (`try/except`), penggunaan modul bawaan, serta dependensi pihak ketiga (`colorama`).

## Panduan Penggunaan

### 1. Membuat dan Mengaktifkan Virtual Environment
Buka terminal pada direktori proyek, lalu jalankan perintah berikut:
- Membuat Virtual Environment: `python -m venv .venv`
- Mengaktifkan Virtual Environment (Windows): `.venv\Scripts\activate`

### 2. Menginstal Dependensi
Setelah virtual environment aktif, instal paket dari file `requirements.txt`:
`pip install -r requirements.txt`

### 3. Menjalankan Program
- Menjalankan program utama: `python halo.py`
- Menjalankan program penampil: `python tampil.py`
